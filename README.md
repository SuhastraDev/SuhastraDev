## Featured Projects

### 1. Kaffe POS & HRIS — Mini ERP

A full-stack operational system for modern cafe management, combining **Point of Sale**, **HRIS**, **payroll**, **inventory**, **attendance**, **reports**, and **QRIS payment integration**.

**Highlights**

* Smart POS with attendance-based cashier access
* Payroll calculation and live salary monitoring
* Inventory and stock management
* QRIS payment using Xendit
* Role-based access for Admin and Cashier
* Sales reports and dashboard analytics

**Tech Stack:** React, Vite, Tailwind CSS, Node.js, Express.js, PostgreSQL, JWT, Xendit

---

### 2. SIMASET — Hospital Asset Management System

A Flask-based asset management system for **RSKGM Palembang**, designed to manage hospital assets, evaluate asset risk using **FMEA**, handle approval workflows, generate QR-coded asset identity cards, and export reports.

**Highlights**

* Hospital asset recording and monitoring
* FMEA risk evaluation using Severity × Occurrence × Detection
* Automatic RPN risk category
* Approval workflow for asset status changes
* QR code generation for assets
* Excel and PDF report export
* Role-based access: Super Admin, Admin Divisi, Admin Ruangan

**Tech Stack:** Python, Flask, SQLAlchemy, MySQL, Flask-Login, Flask-Bcrypt, Bootstrap, WeasyPrint, OpenPyXL, Gunicorn

---

### 3. Flutter Mobile App — Industmesh Mobile

An Android mobile application built with **Flutter** and integrated with backend REST APIs for marketplace-style workflows.

**Highlights**

* Flutter Android development
* Authentication flow
* Project and job detail screens
* Apply job feature using REST API
* Repository-based API structure
* Mobile UI connected to existing backend services

**Tech Stack:** Flutter, Dart, REST API, Mobile UI, Authentication

---

### 4. ZRINTTAILOR — Tailoring Order Management System

A Laravel-based tailoring service platform for managing custom clothing orders, customer communication, payments, order tracking, and AI-assisted measurement validation.

**Highlights**

* Custom clothing order workflow
* Customer and admin dashboards
* Real-time order status tracking
* Chat between customer and admin
* Google OAuth login
* WhatsApp notification integration
* Payment proof verification
* AI/CV-assisted photo validation and body measurement concept

**Tech Stack:** Laravel, PHP, MySQL, Blade, Alpine.js, Tailwind CSS, Google OAuth, Fonnte API, Gemini Vision

---

### 5. Sistem Pendaftaran Magang

A Laravel-based internship registration system that supports online registration, document upload, status tracking, admin review, email notification, PDF generation, and CSV export.

**Highlights**

* Online internship registration
* Participant dashboard
* Admin dashboard and applicant management
* Document upload and preview
* Email notification
* Acceptance letter PDF generation
* CSV export

**Tech Stack:** Laravel, PHP, MySQL, Tailwind CSS, Vite, Mailtrap, DomPDF

---

### 6. Website Arsip Surat

A web-based document archive system for managing incoming and outgoing letters with role-based access and document visibility per user.

**Highlights**

* Incoming and outgoing letter management
* Admin and staff roles
* Document upload
* User-specific document access
* Dashboard summary
* Letter category and tracking workflow

**Tech Stack:** Laravel, PHP, MySQL, Blade, Tailwind CSS, Vite
